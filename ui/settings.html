Magpie-Hana

把 magpie 接入 Hana 的桥。exe 与它的全部数据都在本 App 的数据目录里，不写你的用户目录。

运行状态
正在读取…
主题
自动 = 跟随 Hana 当前主题，你在 Hana 里换，卡片里 5 秒内跟上。也可以钉住某一套 Hana 主题。
卡片里那个「外观」下拉与本清单逐项一致（同一个存储），改哪边另一边都会跟上。
工作区里的功能
开关表示这个功能是否出现在工作区里：开着 = 显示中，关掉 = 隐藏入口（只隐藏入口，不解除底层能力）。改动立即生效，重新打开工作区即可看到。

版本与更新说明。说明内容来自 GitHub Release，不随 App 打包；关掉更新提示后仍可在这里手动看。检查间隔到点就会自动去查一次。
